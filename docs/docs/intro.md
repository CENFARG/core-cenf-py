# What is core-cenf?

**core-cenf** is a reusable infrastructure library for Python 3.12+ providing 17 horizontal transversal managers following Clean Architecture (Ports &amp; Adapters). Every CENF program — backend APIs, AI agents, workflows, UIs — uses these managers for all cross-cutting concerns. You never write config loading, logging, error handling, or observability from scratch again.
